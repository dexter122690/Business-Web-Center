075 - Pause the old/hidden Inventory for 15M Autocare Services

Scope
- Business ce3d6ecf-239e-4b27-a1f6-0ce7ddd16875 only, all branches (STO. TOMAS / STA. ROSA).
- Expense inserts/updates no longer run the old stock copy for this business.
- Authenticated app users cannot insert/update/delete old stock movements or old
  opening counts/cutovers, including from a previously opened browser.
- Existing SELECT permissions remain; existing rows are not changed or deleted.
- Other businesses' automatic stock sync and manual access rules remain unchanged.
- No changes to current inventory_tracker_* tables/RPCs, Expenses, invoices,
  Dashboard calculations, payroll, employee-name pickers, or the payroll draft.

Storage and behavior
- This stops NEW legacy stock entries; it does not reclaim existing storage.
- The hidden screen may still read old history. Reads do not add stock records.
- The old stock balance is now historical, not a current balance.
- Ordinary source-record cleanup remains: deleting an Expense later still uses
  its existing foreign-key cascade. This pause does not change Expense behavior.
- This is a database-only update. No frontend push or refresh is needed to enforce
  it, and no shared inventory permission helper was disabled.
- Do not rerun 022_inventory.sql: it re-enables the original trigger and backfills.

  materials/vehicles/usage/adjustments/costs/reference prices and their history.
