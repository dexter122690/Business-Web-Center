CARWASH — deployment notes
Status: LOCAL PREVIEW ONLY. Owner chose "Local preview muna" on 2026-11-25.
Do not apply to production or publish this frontend without new approval.

Owner decision: carwash services are NOT entered again in Invoice Making.
New units default to Ongoing and may have a blank price (not paid / no income).
Mark done works with or without a price. Reopen corrects accidental completion.
Work status never changes the receipt amount; editing a price preserves status.
Any entered positive price means paid, regardless of Ongoing/Done. The row date
remains the income date. Separate service/payment dates are not yet supported.
This monitoring update is part of the unshipped 092 local-preview migration.

Migration 092 adds only carwash_records and carwash_events, their RLS/select grants,
and two carwash RPCs. No existing records, invoice numbers, cash transactions,
inventory, payroll, expense or remittance records are changed. No imports occur.
Existing Invoice Making branch view/edit permissions are reused; only the owner
can void rows. Voided records are retained with before/after audit history.
Dashboard, executive Excel and print count only priced active receipts once, grouped
as Carwash income, based on the saved date and selected branch/period.
It does not add to the CIB cash-in-hand card (payment method is not collected).

Apply the additive migration before publishing the new frontend. Review the
production scope with the owner before running it. If not installed, the CARWASH
screen stays read-only with a setup message and old dashboard receipts continue.
To roll back the UI, deploy the previous frontend; preserve these new tables.
Never drop the tables to roll back once real records exist.
